## Install venv

```bash
python3 -m venv venv
```

```bash
python --version
```

```bash
source venv/bin/activate
```

```bash
python -m pip install --upgrade pip
```

## Install Django

```bash
python -m pip install Django
```

```bash
python -m django --version
```

## Save and install requirements

```bash
pip freeze > requirements.txt
```

```bash
pip install -r requirements.txt
```
